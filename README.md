# CyberShield

A responsive educational dashboard that helps people practice safer online habits. It includes a personal checklist, sample device reminders, dismissible scam-awareness tips, and an emergency guidance panel.

## Run locally

Open `index.html` in a browser. For installable-app and offline features such as the web app manifest and service worker, serve the folder from a secure local web server (for example, VS Code Live Server). No build step or external dependencies are required.

## Privacy and scope

CyberShield is a static educational demo. Checklist state exists only in the open page. It does not inspect devices, scan or verify links, monitor messages, collect personal information, or provide emergency response. Device and alert content is illustrative sample data.
